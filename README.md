# AuftragsKette

Geschlossenes Empfehlungsnetzwerk für Unternehmer und Selbstständige.

Die App liegt im Ordner [`app/`](app/) (Next.js + Tailwind CSS).

## Lokal starten

```bash
cd app
npm install
npm run dev
```

Dann im Browser http://localhost:3000 öffnen.

## Einrichtung

Anmeldung und Datenbank laufen über Supabase. Schritt-für-Schritt-Anleitung: [SETUP.md](SETUP.md)
